# Web-Scaraper

This project is a simple web scraper built with Python that extracts top news headlines from a website. It uses the requests library to fetch webpage content and BeautifulSoup to parse HTML and extract headline data. The scraped headlines are then saved to a .txt file for offline viewing.

# Features

- Fetches webpage content using requests
- Parses HTML with BeautifulSoup
- Extracts news headlines automatically
- Saves headlines to a text file
- Beginner-friendly project for learning web scraping

# Technologies Used

- Python 3
- Requests
- BeautifulSoup4

 # Install the required packages:
 
```bash
pip install requests
pip install beautifulsoup4
```
